# Music credits

Battleship 1.6 bundles edited orchestral recordings under CC0-1.0.
The app code license does not replace the source music terms.

| Use | Original title | Artist | Source |
| --- | --- | --- | --- |
| Menu and match opening | Determined Pursuit (epic orchestra loop) | Emma_MA | https://opengameart.org/content/determined-pursuit-epic-orchestra-loop |
| Victory | Victory Theme for RPG | cynicmusic | https://opengameart.org/content/victory-theme-for-rpg |
| Defeat | Game Over | Kistol | https://opengameart.org/content/game-over |

The source pages identify CC0 and make attribution optional. We retain credit to the composers.
CC0 dedication: https://creativecommons.org/publicdomain/zero/1.0/

The menu uses the complete 108-second loop. The opening uses its first six seconds.
Victory uses a 12-second excerpt. Defeat uses the full 15-second track.
One-shot edits add short fades. All tracks use constant gain changes and stereo Ogg Vorbis compression.
The source and asset hashes, edits, and measured levels are in `docs/battleship/music-polish/assets.json` from the repository root.
