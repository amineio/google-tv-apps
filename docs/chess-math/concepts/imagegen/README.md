# ImageGen visual exploration

Date: 2026-10-26. Status: proposed visual direction, pending parent approval.

These images use the built-in ImageGen tool. They are design inspiration, not app screenshots or tested TV interfaces. The earlier SVG concepts remain available as interaction references. No product code changed.

## Forest green and ivory

[Chess concept](chess-forest-ivory.png) and [math concept](math-forest-ivory.png) share a quiet forest-green background, warm ivory text, outlined pieces, and large focus markers. The math screen retains the twelve-key number pad, Hint, delete, submit, and paper reminder.

The first generated chess draft omitted a rank. A targeted edit restored eight ranks and eight files. The retained concept shows the standard starting position with White at the bottom. Generated geometry, text, and piece art still require deterministic implementation and TV review. The image does not establish legal-move behavior.

For implementation, keep an accurate square board, safe TV margins, separate focus and selection states, capture markers, and readable check indicators. Reduce decorative texture if it competes with the board. The numeric keypad needs a clearer focus border than its ordinary key borders. These details remain part of the existing design requirements.

Elegant highly readable rounded sans-serif typography, warm ivory titles, sparse muted mint accents, warm amber selection. No gradients on buttons, no glassmorphism, no nested cards, no tiny labels, no decorative mascots, no rewards, no coins, no clocks, no timers, no move-history clutter, no ads. Composition must be credible to implement using native Android views, not a fantasy illustration. All text in Dutch exactly as specified. Make the screen feel finished, calm, welcoming, exceptionally well art-directed, high contrast and usable from a sofa. Do not include any other text.
