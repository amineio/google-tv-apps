# Schaak & Reken — proposed screens

These static SVG concepts show layout, copy, and remote focus. They are not screenshots or implemented Android screens. Dutch and the visual direction remain proposals. The parent settings summary on screen 6 illustrates the controls behind the hold action; it is not simultaneously interactive with Pause.

1. [Start](01-start.svg) — saved session and disclosed round requirements.
2. [Chess](02-chess.svg) — White knight selected, focus on f3, legal dots, and last-move hatching.
3. [Promotion](03-promotion.svg) — four named pieces, explicit confirmation.
4. [Math](04-math.svg) — one problem, fixed number pad, hint, and paper reminder.
5. [Hint and retry](05-hint-retry.svg) — a worked step and an optional solution.
6. [Pause and parent controls](06-pause-parent.svg) — resume first; adult controls and override proposal.
7. [Parent math settings](07-parent.svg) — real focusable controls for families, number limit, crossing ten, tables 1..10, Save, and Cancel.

The arithmetic concepts illustrate crossing ten enabled; the proposed initial setting is disabled. The chess concept uses Unicode pieces only for this review artifact. Product pieces require original vectors and TV contrast checks. Read the [design](../../superpowers/specs/2026-10-26-chess-math-design.md) for capture/check markers, focus behavior, handoffs, state recovery, and approval decisions.
