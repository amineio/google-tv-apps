# Postbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a native TV post library with an Android phone capture activity and private, explicit local transfer.

**Architecture:** One independent Kotlin APK contains TV and phone activities. A core owner implements capture validation, atomic private storage, pinned TLS, and the bounded transfer protocol; a UI owner implements native flows against that contract. The coordinator owns builds, device input, integration, and delivery, with independent concept and final review.

**Tech Stack:** Kotlin `2.4.21`, Compose compiler `2.4.21`, AGP `9.4.1`, Gradle `9.6.0`, JDK 17, Compose BOM `2026.09.00`, TV Material `1.1.0`, kotlinx serialization/coroutines, AndroidKeyStore, platform TLS, and ZXing core `3.5.4`.

**Spec:** [Postbox design](../specs/2026-10-30-postbox-design.md)

Public contract to implement in the named core files:

```kotlin
@Serializable data class PostCapture(
    val id: String,
    val title: String,
    val text: String,
    val sourceUrl: String,
    val imagesJpegBase64: List<String>,
    val capturedAtEpochMs: Long,
)
@Serializable data class StoredCapture(
    val capture: PostCapture,
    val archived: Boolean = false,
    val sent: Boolean = false,
)
enum class SaveResult { ADDED, ALREADY_PRESENT, CONFLICT, FULL }

class CaptureCodec {
    fun canonicalBytes(capture: PostCapture): ByteArray
    fun decode(bytes: ByteArray): PostCapture
    fun digest(capture: PostCapture): String
    fun normalizeSourceUrl(sourceUrl: String): String
}
class PostboxStore(directory: File) {
    fun list(): List<StoredCapture>
    fun save(capture: PostCapture): SaveResult
    fun archive(id: String, archived: Boolean)
    fun markSent(id: String)
    fun delete(id: String)
}
data class PairingLink(val host: String, val port: Int, val pin: String, val token: String) {
    fun encode(): String
    companion object { fun parse(value: String): PairingLink }
}
@Serializable data class PairedTv(
    val host: String, val port: Int, val pin: String, val token: String, val name: String,
)
data class ReceiverSession(val pairingLink: String, val expiresAtEpochMs: Long)

class PostboxClient {
    fun pair(link: PairingLink): PairedTv
    fun send(tv: PairedTv, capture: PostCapture): SaveResult
}
class CaptureReceiver(context: Context, store: PostboxStore, onReceived: () -> Unit) {
    val isReceiving: Boolean
    fun start(): ReceiverSession
    fun close()
    fun forgetPhone()
}
```

All core classes use package `com.amine.postbox.core`. `sourceUrl` is an empty string when absent. `CaptureCodec` validates before encoding and after decoding; invalid input throws one bounded, safe validation error. Store and client methods are synchronous; the view model and server always call them on `Dispatchers.IO` or a bounded background worker. `PostboxStore` serializes mutations. Store exceptions propagate as safe operational failures, never false success. An edited draft gets a new UUID; replace the old draft only after saving the new capture succeeds.

`CaptureReceiver.start()` determines the LAN IPv4 address, binds a stable available port, creates the five-minute window, and returns its actual pairing link and display expiry. No usable local address is a visible operational error. Expiry enforcement uses a monotonic clock even though the public expiry is epoch time for display. The receiver owns native AndroidKeyStore identity and token persistence. `isReceiving` is a cheap state getter for the UI; reading it must not perform network or disk work. The UI persists `PairedTv` privately and invokes receiver start/close from the resumed Add posts lifecycle. Token replacement and forgetting remain owned by the core protocol. Injectable clocks and test sockets may remain internal.
