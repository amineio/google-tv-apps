# Family Home settings validation

## Scope

The change separates Profiles, Parent PIN, and Device setup into TV lists.
Each installed app has one switch row in the child's Allowed apps list.
The parent can save a new child profile. Delivery does not create a real profile.
The existing three profiles, portraits, timers, app lists, and PIN remain in place.

## Evidence so far

The clean main baseline passed 32 unit tests.
The new profile regression failed against the fixed enum before implementation.
The profile implementation passed 46 unit tests.
An independent reviewer accepted its specification coverage and code quality without material findings.
The settings navigation regression failed on the emulator before the new settings implementation.

## Installed upgrade

The isolated emulator used the previous 1.2 debug APK and its schema-1 DataStore.
The previous runtime accepted a private fixture with two paused balances, an enabled PIN, and one modified child app list.
The fixture deliberately omitted the other child's app-list entry.
The schema-2 debug APK replaced the APK without clearing data.
The comparison kept exactly three profile records.
Both session records, the entire app-list map, the PIN fields, and the paused selection were equal before and after.
The normal load operation advanced the recovery revision.
Raw records stay outside Git.

## Native settings evidence

Both debug and release variants passed 46 unit tests each.
Release lint completed without errors. Debug, release, and Android test APKs built locally.
The isolated emulator passed all 27 instrumented tests.
These tests cover switch persistence, scrolling, focus restoration, PIN dialogs, cancelled creation, explicit Save, duplicate names, and recreation.
A delayed-write regression proves that Back after Save does not cancel the durable command or reopen the form.
Each settings page owns a separate scrolling list to prevent old focus requests from crossing page changes.
Completed creation clears the form before another profile is added.

## Remaining evidence

The completed implementation still requires final independent review and physical installation.
Emulator layout tests do not establish streaming playback, Cast, or physical wake behavior.
