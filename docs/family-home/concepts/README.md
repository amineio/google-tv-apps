# Family Home visual concepts

Date: 2026-10-28.

These images are design references from the built-in image generation tool.
They are not screenshots of the app.
The user requested a more refined design inspired by Google TV and YouTube.
Amine approved both screens and requested implementation on 2026-10-28.
Version 1.1 uses this direction with native text, app data, controls, and focus behavior.

[Profile entry](profile-entry.png) uses three circular avatars, clear text, and a restrained gold focus ring.
[Child home](child-home.png) uses a featured app, landscape app tiles, and a visible session timer.
The app artwork illustrates the proposed layout. It does not add content recommendations or viewing history.

## Prompt summaries

Profile entry: Create a high-fidelity, 16:9 Android TV family launcher concept inspired by Google TV and YouTube.
Use a dark charcoal background, readable off-white text, and a subtle warm gradient.
Show Family Home, a clock, and the heading “Who is watching?”.
Show exactly three circular illustrated avatars with the labels Amine, Elias, and Sofia.
Give Amine a thin gold focus ring. Use generous space and consistent alignment.
Exclude ads, extra profiles, oversized pill buttons, device frames, and busy decorations.

Child home: Create a matching 16:9 TV concept with Elias and “20:00 left” in the header.
Feature Chess & Math with chess artwork and an Open app button.
Show one row with Chess & Math, MasterClass, VTM GO, VRT MAX, Spotify, and Prime Video.
Use landscape tiles, a restrained gold focus outline, and a quiet Switch profile control.
Exclude YouTube, RTBF Auvio, ads, program recommendations, viewing history, and device frames.
